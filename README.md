What I learned:
INNER JOIN: Returns only rows where the join condition is true on BOTH sides. Unmatched rows are 
dropped/ no duplicates.

LEFT JOIN: Returns every row from the LEFT or BASE table. Matching rows from the right are included; unmatched 
rows on the right become NULL.

FULL OUTER JOIN: Returns every row from BOTH tables. Unmatched rows on either side become NULL on the 
other side's columns

The same two tables joined in three different ways give you three different 
answers — and choosing the right one is half the skill
